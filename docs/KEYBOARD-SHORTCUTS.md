# Phím tắt

Nhấn **F1** hoặc bấm biểu tượng bàn phím trên thanh trên để mở bảng phím tắt có tìm kiếm. Có thể tìm bằng tiếng Việt không dấu, ví dụ `in dam`. Trong chế độ tập trung, F1 vẫn dùng được. Nhấn Esc để đóng và quay về vị trí đang làm việc.

Trong bản thảo, bôi đen văn bản rồi dùng phím tắt để đổi định dạng. Có thể bật định dạng trước khi gõ. Khi con trỏ ở ô tiêu đề, ô tìm kiếm hay hộp thoại, các phím định dạng không thay đổi bản thảo. Bản Tổng hợp chỉ cho xem.

| Thao tác | Windows | Mac |
| --- | --- | --- |
| In đậm | Ctrl+B | ⌘+B |
| In nghiêng | Ctrl+I | ⌘+I |
| Gạch chân | Ctrl+U | ⌘+U |
| Gạch ngang | Ctrl+Shift+S | ⌘+Shift+S |
| Hoàn tác | Ctrl+Z | ⌘+Z |
| Làm lại | Ctrl+Y hoặc Ctrl+Shift+Z | ⌘+Y hoặc ⌘+Shift+Z |
| Lưu ngay trên máy | Ctrl+S | ⌘+S |
| Tìm trong bản thảo | Ctrl+F | ⌘+F |
| Thay thế | Ctrl+H | ⌘+Alt+F |
| Chèn/sửa liên kết | Ctrl+Shift+K | ⌘+Shift+K |
| Bảng lệnh | Ctrl+K | ⌘+K |
| Chèn công thức | Ctrl+Shift+M | ⌘+Shift+M |
| Chèn trích dẫn | Ctrl+Shift+C | ⌘+Shift+C |
| Ngắt trang | Ctrl+Enter | ⌘+Enter |
| Xóa định dạng chữ và căn lề | Ctrl+\ | ⌘+\ |
| Tiêu đề cấp 1–3 | Ctrl+Alt+1–3 | ⌘+Alt+1–3 |
| Đoạn văn thường | Ctrl+Alt+0 | ⌘+Alt+0 |
| Danh sách đánh số / gạch đầu dòng | Ctrl+Shift+7 / 8 | ⌘+Shift+7 / 8 |
| Căn trái / giữa / phải / đều | Ctrl+Shift+L / E / R / J | ⌘+Shift+L / E / R / J |

Trên Mac, Alt còn được gọi là Option. Không dùng ⌘+H cho thay thế vì hệ điều hành dành tổ hợp này để ẩn ứng dụng.

Trong khung LaTeX, các phím sửa mã, tìm kiếm và hoàn tác do CodeMirror xử lý. Ctrl+S/⌘+S vẫn lưu ngay tài liệu hiện tại; F1 và bảng lệnh dùng chung cho ứng dụng. Phím định dạng chữ của bản thảo không chèn lệnh LaTeX vào source.

Danh sách đầy đủ và tổ hợp đúng nền tảng được lấy từ `src/services/KeyboardShortcuts.js` và hiển thị trực tiếp trong bảng F1.
